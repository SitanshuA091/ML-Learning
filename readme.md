# Transformer (Work in Progress)

This is the implementation of Transformer from scratch on machine translation task

## Dataset

* Hindi–English sentence pairs dataset from manythings.org
* File: `hin.txt`
* Format: English \t Hindi

## Model

* Encoder–Decoder Transformer
* Implementation from scratch
* Architecture based on the original paper:
  "Attention Is All You Need" by Ashish Vaswani et al.

## Status

* Work in progress
* Core components being implemented and tested
